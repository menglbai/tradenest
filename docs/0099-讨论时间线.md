## 时间线

### 阶段一：方向确认（2026-05-12 晚 ~ 2026-05-13 上午）

#### 立项背景

项目作者（小红书工程师，AI Agent 平台负责人）希望做一个个人项目：
- 业余时间 6-12 个月可以完成
- 用上 Claude Code 全部核心技术（context mgmt / memory / tools / skills / hooks / sub-agent）
- 偏技术沉淀 + 简历加分，未来或可商业化
- **必须能 dogfood**（作者本人是首要用户）
- 严守合规红线（金融领域尤其）

#### 决定做"AI 投资研究伙伴"方向

经过多个候选方向的探索，最终聚焦到"AI 投资研究伙伴"——

理由：
1. **作者本人在做投资**——能 dogfood
2. **技术深度足够**：Agent 内核 + 5 层记忆 + 实时市场感知 + 多 Agent 编排
3. **合规可控**：定位"研究伙伴"而非"投顾"
4. **市场真实存在**：TradingAgents-CN 的 26554 stars 验证

#### 关键担忧（用户提出，已解决）

> "Investia 这个东西到时候不一定可靠，跟政治、国际形势、特朗普一句话都有很大影响"

**解决思路**：
- TradeNest 的定位**不是"帮你赢市场"**——是"帮你管理投资这件事的过程"
- 苏格拉底式对话 / 持久记忆 / 跨时间复盘 这些价值，**不被特朗普一句话打败**
- 对比错位：用户想要"AI 推荐买卖"——这违法 + 就算合法 AI 也做不到

#### 关键发现：TradingAgents-CN 项目（2026-05-13 11:48）

用户分享 https://github.com/hsliuping/TradingAgents-CN：
- 26554 stars / 5614 forks
- 中文 AI 投资分析的明星项目
- 多 Agent 框架（5 分析师 + 多空辩论 + 三方风控）
- 严格合规定位（"学习平台"，不实盘）

这个发现**带来 4 个关键启示**：
1. **赛道是真的**——26554 stars 不是水的
2. **合规边界清楚**——大家都不敢踩"具体推荐"红线
3. **多 Agent 框架已成熟**——业务流程有 baseline 可借鉴
4. **TradeNest 的差异化**就清楚了：他们没做的就是我们要做的（长期记忆 / 个人化 / 苏格拉底 / 推送 / 复盘）

详见 [REFERENCES.md](./0004-参考项目分析.md)。

### 阶段二：技术栈与代码策略（2026-05-13 11:50 ~ 12:00）

#### 决定：不抄 TradingAgents-CN 代码

用户原话：
> "我希望你能用到 cc 和 OpenClaw 里最新的代码技术，以及行业内最新的研究技术等应用。
> Trading 这个项目的业务功能我觉得你可以参考，但是代码逻辑之类的不需要吧。"

**这是关键决策**——奠定了项目的独立性：
- ✅ 业务功能借鉴（多 Agent / 合规 / 数据源）
- ❌ 代码不抄（保持独立 + 学到技术）

详见 [ADR-007](../DECISIONS.md#adr-007-不集成-tradingagents-cn-代码)。

#### 技术栈确定

经过讨论，2026-05-13 11:58 用户表态：
> "用最好的最合适的就行。"

最终拍板：

| 维度 | 选定 |
|------|------|
| 后端语言 | Python 3.12 |
| 后端框架 | FastAPI |
| Agent 主框架 | Anthropic Claude Agent SDK + LangGraph 混合 |

| 浏览器扩展 | WXT (Manifest V3) |

| 代码质量 | Ruff + mypy strict + Biome |
| 图表 | TradingView Lightweight Charts + ECharts |
| License | Apache 2.0 |

每条决策详见 [DECISIONS.md](./0003-决策日志ADR.md) ADR-002 ~ ADR-013。

#### 关键设计原则

讨论中确认的核心原则：
- **dogfood 优先**：作者本人是首要用户（[ADR-017](../DECISIONS.md#adr-017-dogfood-优先)）
- **苏格拉底式对话**：不替决策，反问引导（[ADR-014](../DECISIONS.md#adr-014-苏格拉底对话不替决策)）
- **5 层持久记忆**：用户画像 / 框架 / 笔记 / 决策 / 对话（[ADR-008](../DECISIONS.md#adr-008-5-层持久记忆系统设计)）
- **三道合规审查**：System Prompt + 输出审查 + 用户协议（[ADR-016](../DECISIONS.md#adr-016-三道合规审查防线)）
- **8 个月路线图**：含 20% buffer（[ADR-015](../DECISIONS.md#adr-015-8-个月路线图不是-12-个月)）

## 已确认的核心定位

### 一句话定位

TradeNest 是一个长期陪伴自主研究型投资者的 AI 投资研究伙伴——
**记忆 / 分析 / 监测 / 反问 / 复盘**，**不替决策**。

### 三个清晰的"是"

- ✅ **是私人研究员**——服务一个人，陪 1-3-5 年
- ✅ **是研究归宿**——所有研究最终汇聚于此
- ✅ **是反思工具**——看见判断的演变

### 三个清晰的"不是"

- ❌ **不是投顾产品**——绝不给买卖建议
- ❌ **不是数据终端**——不跟同花顺/Bloomberg 比
- ❌ **不是社区产品**——不做内容分发

---

## 已确认的合规边界

### 红线（绝对不做）

- ❌ 不推荐具体证券
- ❌ 不预测股价
- ❌ 不替下单
- ❌ 不承诺收益

### 灰区（可做）

- ✅ 信息整理
- ✅ 多视角分析
- ✅ 跨时间反馈
- ✅ 苏格拉底反问
- ✅ 风险提示

详见 [COMPLIANCE.md](./0002-合规边界.md)。

## 给未来接手者的话

如果你正在阅读这份文档，意味着你接手了 TradeNest 项目。请记住：

1. **这是一个长期陪伴产品，不是单次工具**——所有功能围绕"长期"设计
2. **dogfood 是根本**——任何功能都问"作者本人会用吗"
3. **合规是底线**——任何 AI 输出都不能给买卖建议
4. **5 层记忆是灵魂**——这是 TradeNest 跟同类产品最大的差异
5. **苏格拉底对话是哲学**——不替用户决策

如果以上 5 条有冲突，**合规 > dogfood > 长期 > 记忆 > 对话**。

阅读所有文档后，建议：
1. 装好开发环境
2. 跑通 mvp.py
3. 用 1 周时间用 TradeNest 自己（dogfood）
4. 找出最痛的 1 个问题，先解决它
