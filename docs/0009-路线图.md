## 1. 总览

### 1.1 时间线

```
2026-05-13 启动
   │
   ├─ Phase 0  Week 1-4    (5/13 - 6/10)   基础设施
   ├─ Phase 1  Month 2-3   (6/11 - 8/10)   记忆系统
   ├─ Phase 2  Month 4-5   (8/11 - 10/10)  多 Agent + 数据
   ├─ Phase 3  Month 6-7   (10/11 - 12/10) 推送 + 复盘
   └─ Phase 4  Month 8     (12/11 - 1/13)  打磨发布
   │
2027-01-13 v1.0.0 私测
```

### 1.2 各 Phase 主交付

| Phase | 时长 | 主交付 | 验收 |
|-------|------|--------|------|
| 0 | 4 周 | 基础设施 + 单 Agent + AkShare | mvp.py 跑通 |
| 1 | 8 周 | 5 层记忆 + 苏格拉底对话 v1 | 跨会话连续性 |
| 2 | 8 周 | 多 Agent + 全数据 | 多空辩论报告 |
| 3 | 8 周 | 主动推送 + 复盘 | 周报自动生成 |
| 4 | 5 周 | 桌面客户端 + 私测 | 5 用户私测 |

### 1.3 工作模式

- **业余开发**：每周 10-15 小时
- **节奏**：工作日 1-2 晚 + 周末 5-8 小时
- **buffer**：每月留 20% 时间应对意外
- **dogfood**：每个 Phase 结束后用 1 周自己用

## 9. 风险与缓冲

### 9.1 时间风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| 工作太忙没时间 | 高 | 每月 20% buffer + 任务拆细 |
| 完美主义陷阱 | 高 | "ugly first" 原则 |
| 单 Phase 卡死 | 中 | 严格按周 review |
| 工作变动 | 中 | 项目独立、可暂停 |

### 9.2 技术风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| LangGraph 复杂度超出 | 中 | Phase 0 仅用 Anthropic SDK |
| AkShare 不稳定 | 中 | 多接口降级 + Tushare 备选 |
| Tauri 跨平台坑 | 中 | Mac 主用，Win/Linux 后期 |
| LLM 成本超预算 | 低 | 模型路由 + 监控 |

### 9.3 业务风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| 大厂出同类产品 | 高 | 差异化（长期陪伴 + 个人化）|
| 监管收紧 | 中 | 严守红线 + 文档详尽 |
| 作者放弃 | 中 | dogfood 优先 + 文档完整 |

### 9.4 buffer 时间分配

每月预留 20% buffer：
- 处理意外（设备故障 / 工作冲突）
- 修复不可预期的 bug
- 重构（避免技术债爆炸）
- dogfood 反思

如果某 Phase 没用完 buffer：
- 用于深度优化
- 写更多文档
- 提前进入下一 Phase

## 10. 工作时间预估

### 10.1 每周 10-15 小时

```
工作日（周一 ~ 周五）：
- 晚上 21:00-23:00 × 2-3 个晚上 = 4-6 小时

周末（周六 + 周日）：
- 4-8 小时（视家庭情况）

总计：10-15 小时 / 周
```

### 10.2 任务粒度

每个任务**控制在 30 分钟内可推进**：
- ✅ "实现 get_realtime_quote 工具"（30 min）
- ✅ "写 conversation 表 DDL"（15 min）
- ❌ "实现整个记忆系统"（粒度太大）

### 10.3 8 个月总投入

- 8 个月 × 4.3 周/月 × 12.5 小时/周 ≈ **430 小时**
- 约 54 个 8 小时工作日

### 10.4 不要做的事

- ❌ 不连续熬夜（>2 小时晚睡）
- ❌ 不在工作日做超过 2 小时
- ❌ 不在生病 / 状态差时硬推
- ❌ 不为了"赶进度"妥协合规
