## 一、AI 对话核心

| 功能 | 状态 | 说明 |
|------|------|------|
| 多轮对话 | ✅ | 上下文保留，支持追问 |
| 流式输出 | ✅ | 边生成边显示，含打字光标 |
| 工具调用 | ✅ | AI 自动判断调用哪些数据工具 |
| 多工具组合 | ✅ | 一次提问可同时调用行情+资金流+新闻+外盘 |
| 持仓上下文注入 | ✅ | 每次对话自动携带持仓/关注/实时行情 |
| 角色切换 | ✅ | 通用研究员 / 基本面分析师 / 苏格拉底模式 |
| 持仓诊断 | ✅ | 一键分析所有持仓，给出建议 |
| 对话摘要 | ✅ | 一键总结本次对话核心结论 |
| 对话历史持久化 | ✅ | SQLite，重启不丢 |
| 多会话管理 | ✅ | 新建/切换/删除，首条消息自动命名 |
