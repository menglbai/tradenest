### ADR 流程

任何不可轻易回滚的决策：
1. 在 [0003-决策日志ADR.md](./0003-决策日志ADR.md) 末尾加新 ADR
2. PR 描述链接到 ADR
3. 合并后实施

## 文档命名规则

```
NNNN-中文名.md
```

- **NNNN**：4 位序号，0000-0099 为常规，0100+ 为子文档（如有）
- **中文名**：见名知义，避免歧义
- **避免符号**：不用空格、特殊字符（除连字符）

未来增加文档时按编号顺延：
- 0014 - 0019：路线图扩展（如 v2 规划）
- 0020 - 0029：技术深度文档
- 0030 - 0039：用户文档（用户手册等）
- 0099：讨论 / 归档类
